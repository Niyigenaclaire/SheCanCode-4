# SheCanCode-4

This is a responsive web application built with HTML and Tailwind CSS. It features a modern, clean UI with a responsive hero section, a fully functional navigation bar, and dark mode support.

## Features

*   **Responsive Hero Section:** Pixel-perfect layout with a background circle and phone mockup.
*   **Modern Navigation:** Clean, modern header without backdrop blur, providing a solid appearance.
*   **Tailwind CSS:** Fully styled using Tailwind CSS utility classes.
*   **Dark Mode Ready:** Ensures an aesthetic experience across both light and dark themes.

## Getting Started

To view the project locally, simply open the `index.html` file in your preferred web browser.

No complex build steps or installations are required!
